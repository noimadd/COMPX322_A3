Student Study Planner API

Welcome to the Student Study Planner API!

This API allows you to manage your study schedule, track your progress, and stay organised throughout your studies!

API Endpoints

POST
/tasks
Create a new task. Requires a JSON body containing the task details (title, course, due_date, priority, status).
GET
/tasks
Retrieves all tasks.
GET
/tasks/:id
Retrieves a single task by its unique ID. Replace :id with a valid task ID.
GET
/tasks/status/:status
Retrieves tasks by their status (pending, in-progress, completed). Replace :status with the desired status.
GET
/tasks/search/:title
Searches for tasks by title. Replace :title with a keyword to search for in task titles. Note: This can be a partial match
PUT
/tasks/:id
Updates a task by its unique ID. Replace :id with a valid task ID. Requires a JSON body containing the updated task details (title, course, due_date, priority, status).
DELETE
/tasks/:id
Deletes a task by its unique ID. Replace :id with a valid task ID.
DELETE
/tasks
Deletes all tasks from the planner. Note: This action cannot be undone BE CAREFUL

Test Endpoints

GET
Search By Keyword - "Finish"

Request:

GET /tasks/search/Finish

Result:

Returns a JSON array of tasks whose title contain 'Finish'. If there are no matches, an empty array is returned.

GET
Filter By Status - "todo"

Request:

GET /tasks/status/todo

Result:

Returns a JSON array of tasks whose status is 'todo'. If there are no matches, an empty array is returned.

GET
Error - Non-existent ID

Request:

GET /tasks/9999

Result:

Returns a 404 status code with the error message {"error": "No task with ID 9999 found"}
